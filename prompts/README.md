# AI prompt library

These optional prompts extend the local deterministic workflow. Replace the bracketed variables and paste the prompt into the AI assistant of your choice. Never add achievements, skills, or credentials that are not present in the candidate profile.

- `en/`: English prompts.
- `es/`: Spanish prompts.

The desktop application remains fully usable without an AI service or API key.

## Relación con la Fase 4

Estos prompts siguen siendo manuales; el programa no llama a un modelo ni envía
CV a terceros. La generación integrada de CV compone hechos literales respaldados.
Si se usa un asistente externo por decisión propia, revisar privacidad, evidencia
y cambios antes de importar una versión nueva y aprobarla. Un texto generado fuera
del programa no conserva automáticamente la huella o autorización de otro documento.
